# Great-Star

말 한마디로 만든 **AI 비서실장 "마리코"** 와, 마리코랑 대화하는 **아이메시지 스타일 채팅창**.

터미널 검은 화면 대신 채팅창에서 지시하면, 마리코가 부서를 배정하고 파일까지 만들어 둡니다.

```
마리코  로지님, 비서실장 마리코입니다. 지시하시면 즉시 해당 부서로 배정하고 처리하겠습니다.
 로지                 와이즈바이옴 제품 시장상황 정리하고, 안내 메일 초안도 써줘
마리코  전략기획실과 카피라이팅실로 나눠 배정했습니다. 시장 정리는
        `산출물/와이즈바이옴_시장정리.md`, 메일 초안은 `산출물/박혜명_안내메일.md`에
        있습니다. 발송 전에 한 번 보시겠습니까?
```

## 실행

맥에서는 **`켜기.command` 파일을 더블클릭**하면 됩니다.

터미널에서 직접 켜려면:

```bash
python3 server.py
```

브라우저에서 <http://localhost:8765> 를 엽니다. 설치할 패키지는 없습니다 (파이썬 3.9+ 표준 라이브러리만 씁니다).

## 응답을 만드는 세 가지 방법

서버가 켜질 때 쓸 수 있는 것을 자동으로 고르고, 어느 쪽인지 터미널에 찍어 줍니다.

| 방식 | 조건 | 할 수 있는 일 |
|---|---|---|
| **cli** (권장) | [Claude Code](https://claude.com/claude-code)가 설치·로그인되어 있을 때 | `마리코/` 폴더에서 실행돼 CLAUDE.md와 부서 문서를 읽고, **파일을 직접 만들고 고칩니다.** |
| **api** | `ANTHROPIC_API_KEY` + `pip install anthropic` | 대화만 합니다. 파일 작업은 하지 않습니다. |
| **demo** | 위 둘 다 없을 때 | 정해진 문구로 답합니다. 화면만 확인할 때. |

`MARIKO_BACKEND=demo python3 server.py` 처럼 직접 지정할 수도 있습니다.

## 폴더 구조

```
켜기.command          맥에서 더블클릭으로 켜기 (열어둘 폴더·자동 저장 설정이 들어 있음)
server.py             채팅 서버 (SSE 스트리밍, 표준 라이브러리만)
index.html            채팅창 한 장짜리 (아이메시지 스타일, 다크모드 지원)
마리코/
  CLAUDE.md           마리코의 인격과 업무 규칙. 이 파일이 곧 비서다.
  profile.json        이름·직함·소개·추천 문구 (채팅창 상단과 프로필 카드에 쓰임)
  부서/
    전략기획실.md      시장·경쟁사 조사, 기획 초안
    재무관리팀.md      자산 현황, 지출 정리, 예산
    카피라이팅실.md    메일·공지·SNS 문구
  업무기록/           날짜별 업무 로그 (마리코가 직접 남김)
  산출물/             마리코가 만든 문서
```

## 채팅창에서 되는 것

- 답이 **한 글자씩 흘러나옵니다** (SSE 스트리밍).
- 파일을 읽거나 쓰는 동안 "자료를 확인하는 중…" 같은 상태가 뜹니다.
- 길어지면 **멈춤** 버튼으로 중간에 끊을 수 있습니다.
- 상단 이름을 누르면 프로필 카드, 왼쪽 ☰ 를 누르면 부서 목록과 **새 대화** 버튼이 나옵니다.
- 대화는 이어집니다. 새 대화를 누르기 전까지 앞의 내용을 기억합니다.

## 마리코가 만든 것 계속 쌓아 두기

마리코의 결과물은 전부 `마리코/` 폴더 안에 파일로 남습니다. 이 폴더만 챙기면 됩니다.

### 방법 1 — iCloud에 두고 모든 기기에서 보기

`Great-Star` 폴더째로 iCloud Drive에 옮기면 끝입니다. 맥·아이패드·아이폰에서 자동으로 동기화됩니다.

```bash
mv ~/Great-Star ~/Library/Mobile\ Documents/com~apple~CloudDocs/Great-Star
cd ~/Library/Mobile\ Documents/com~apple~CloudDocs/Great-Star
python3 server.py
```

앞으로는 Finder 사이드바의 **iCloud Drive → Great-Star → 마리코** 에서 바로 열어 보면 됩니다.
드롭박스나 구글 드라이브를 쓰셔도 방식은 같습니다. 폴더를 그쪽으로 옮기고 거기서 실행하면 됩니다.

### 방법 2 — git으로 기록 남기고 GitHub에 백업

언제 무엇이 바뀌었는지 남고, 실수로 지워도 되돌릴 수 있습니다.

```bash
MARIKO_AUTOSAVE=commit python3 server.py     # 내 컴퓨터에만 기록
MARIKO_AUTOSAVE=push   python3 server.py     # GitHub까지 올리기
```

대화가 한 번 끝날 때마다 `마리코/` 폴더의 변경사항이 `마리코 자동 저장 2026-08-22 14:33` 같은
이름으로 저장됩니다. 바뀐 게 없으면 아무 일도 하지 않습니다.
`server.py`나 `index.html` 같은 코드는 건드리지 않고, `마리코/` 폴더만 저장합니다.

지난 기록을 보려면:

```bash
git log --oneline -- 마리코/          # 언제 무엇이 저장됐는지
git show <커밋번호>                    # 그때 바뀐 내용
```

### 둘 다 쓰기

iCloud에 폴더를 두고 `MARIKO_AUTOSAVE=commit`으로 실행하면, 기기 간 동기화와 되돌리기가 같이 됩니다.
가장 무난한 조합입니다.

## 맥의 앱과 폴더 다루게 하기

마리코는 기본적으로 `마리코/` 폴더 안에서만 움직입니다. 밖으로 넓히려면 두 가지를 열어 줘야 합니다.

### 폴더 — 서버에서 열어 줍니다

```bash
MARIKO_ADD_DIR="$HOME/Desktop:$HOME/Documents" python3 server.py
```

`켜기.command`를 쓰시면 이미 바탕화면과 문서 폴더가 열려 있습니다. 다른 곳을 더하려면 그 파일을 열어
`MARIKO_ADD_DIR` 줄에 콜론으로 이어 붙이세요. 서버 시작 화면의 **"열어둔 폴더"** 줄에서 확인할 수 있습니다.

옵시디언은 결국 마크다운 파일 폴더라, 볼트 경로만 열어 주면 앱 조종 없이 바로 읽고 씁니다.

### 앱 — 맥 권한이 필요합니다

캘린더·메시지·연락처·Pages 같은 앱은 맥의 "자동화" 권한이 **앱마다 한 번씩** 필요합니다.
한 번에 몰아서 승인해 두는 게 편합니다.

```bash
cd ~/Great-Star/마리코
claude
```

띄운 뒤 `/permissions` 에서 Allow에 `Bash(osascript:*)` 를 추가하고 (처음이라면 폴더 신뢰 다이얼로그에
먼저 "Yes, I trust this folder"), 이렇게 시켜 보세요.

```
osascript로 캘린더, 미리 알림, 연락처, 메시지, Pages에서 각각 하나씩만 읽어서 보여줘
```

앱마다 "터미널이 OO을(를) 제어하려고 합니다" 창이 뜹니다. 전부 **확인**을 누르면 끝입니다.
실수로 거부했다면 시스템 설정 → 개인정보 보호 및 보안 → **자동화** → 터미널 에서 체크하면 됩니다.

바탕화면·문서 폴더는 "파일 및 폴더" 권한 창이 따로 한 번 뜰 수 있습니다. 같이 허용해 주세요.

### 문자와 전화

`마리코/CLAUDE.md`에 **보내기 직전에 받는 사람과 내용을 보여 주고 확답을 받은 뒤에만 실행**하도록
규칙을 박아 뒀습니다. "알아서 보내"라고 해도 확인을 건너뛰지 않습니다.
그래도 밖으로 나가는 일이니, 처음 몇 번은 확인 문구를 꼭 읽고 넘기시길 권합니다.

## 내 비서로 바꾸기

1. `마리코/profile.json`에서 이름·직함·소개·추천 문구를 고칩니다. 채팅창에 바로 반영됩니다.
2. `마리코/CLAUDE.md`에서 호칭(`로지님`)과 말투 규칙을 바꿉니다.
3. 부서를 더 두고 싶으면 `마리코/부서/`에 문서를 하나 추가하고, `CLAUDE.md`의 부서 표에 한 줄 넣습니다.

폴더 이름을 바꿨다면 `MARIKO_DIR=새폴더명 python3 server.py`.

## 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `MARIKO_PORT` | `8765` | 포트 |
| `MARIKO_HOST` | `127.0.0.1` | 바인딩 주소 |
| `MARIKO_BACKEND` | `auto` | `cli` / `api` / `demo` |
| `MARIKO_MODEL` | `claude-opus-5` | 사용할 모델 |
| `MARIKO_DIR` | `마리코` | 비서 폴더 이름 |
| `MARIKO_PERMISSION_MODE` | `acceptEdits` | cli 백엔드 권한 모드 |
| `MARIKO_CLAUDE_BIN` | 자동 탐색 | `claude` 실행 파일 위치를 직접 지정할 때 |
| `MARIKO_AUTOSAVE` | 꺼짐 | `commit` = 대화가 끝날 때마다 git에 기록, `push` = GitHub까지 |
| `MARIKO_ADD_DIR` | 없음 | 마리코가 읽고 쓸 수 있는 폴더를 더 열어 줌. `~/Desktop:~/Documents` 처럼 콜론으로 구분 |
| `MARIKO_TIMEOUT` | `300` | 한 번의 응답 제한 시간(초) |

## 알아 두실 것

- 기본은 `127.0.0.1` 바인딩입니다. **로그인이 없는 서버이므로 그대로 외부에 열지 마세요.**
- cli 백엔드는 `acceptEdits` 권한으로 돌아, 마리코가 `마리코/` 폴더 안에서 파일을 만들고 고칩니다.
  더 조심스럽게 쓰려면 `MARIKO_PERMISSION_MODE=manual`로 두세요. 다만 권한 요청은 채팅창에
  뜨지 않아서 응답이 멈춘 것처럼 보일 수 있습니다.
- 메일 발송·결제처럼 되돌릴 수 없는 일은 `CLAUDE.md` 규칙상 항상 확인을 먼저 받습니다.
