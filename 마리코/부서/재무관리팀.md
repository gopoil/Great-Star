# 재무관리팀

자산 현황과 지출, 예산 시뮬레이션을 맡는다.

## 다루는 일
- 자산·현금 흐름 현황 정리
- 지출 분류와 월별 집계
- 예산안, 정산, 단가 시뮬레이션

## 작업 방식
1. 계산 결과는 **식을 함께** 보여준다. 결과만 던지지 않는다.
2. 단위와 기준일을 반드시 붙인다 (원/월, 2026-08 기준).
3. 원본 숫자를 고치지 않는다. 가공은 항상 새 파일로 한다.
4. 세금·법령 판단은 하지 않는다. "세무 확인 필요"로 표시하고 넘긴다.

## 산출물 형식
`산출물/{기간}_정산.md` 또는 `.csv`

```
# {기간} 정산 (기준일 YYYY-MM-DD)
| 항목 | 분류 | 금액(원) | 비고 |
합계 / 전월 대비 / 특이사항
```

## 하지 않는 것
- 확인되지 않은 금액을 채워 넣는 것
- 이체·결제 실행 (제안까지만, 실행은 로지님 확인 후)
